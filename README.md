# IBM Guided Python Data Project

## Overview
This project analyzes historical stock prices and revenue data for Tesla (TSLA) and GameStop (GME) using Python. It was completed as part of the IBM Python Project for Data Science course.

## Technologies Used
- Python
- yfinance
- Pandas
- Requests
- BeautifulSoup
- Matplotlib

## Key Tasks
- Retrieved historical stock data using `yfinance`.
- Extracted revenue data from web pages using BeautifulSoup.
- Cleaned revenue data using Pandas.
- Created visualizations to compare historical stock prices and revenue.

## Data Sources
- Stock prices: Yahoo Finance via `yfinance`
- Revenue data: IBM Skills Network course-provided web pages

## How to Run
1. Clone this repository.
2. Install the required libraries:
   `pip install yfinance pandas requests matplotlib beautifulsoup4`
3. Run the Python script.

## Learning Outcomes
This project helped me practice retrieving financial data, web scraping, data cleaning, and data visualization with Python.
